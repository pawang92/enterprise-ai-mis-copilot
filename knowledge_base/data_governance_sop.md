# Data Governance SOP

## Data quality
Validate required columns, date formats, numeric fields,
duplicate records, and missing values before reporting.

## Access control
Only authorized users may access restricted datasets
and reports.

## Auditability
Record report generation time, source dataset version,
analysis results, and supporting document references.

## Privacy
Use approved data only. Do not include patient-identifiable
information in general-purpose analytics or AI prompts.
